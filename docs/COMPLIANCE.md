# Compliance Documentation

## Healthcare Standards

### HIPAA (U.S.)
- Privacy Rule: Patient data protection
- Security Rule: Technical safeguards
- Breach Notification Rule: Incident procedures
- Business Associate Agreements: Vendor management

### GDPR (EU)
- Lawful basis for processing
- User rights (access, deletion, portability)
- Data protection impact assessment (DPIA)
- Incident notification (72 hours)

### HL7 FHIR
- Healthcare data interoperability standard
- RESTful API design
- Resource-based approach
- JSON support

## Compliance Checklist

- [ ] HIPAA Risk Analysis
- [ ] GDPR DPIA
- [ ] Penetration Testing
- [ ] Vulnerability Assessment
- [ ] Staff Training
- [ ] Incident Response Testing
- [ ] Backup & Recovery Testing
- [ ] Annual Audit

## Audit & Logging

All actions logged with:
- User ID
- Action type
- Resource accessed
- Timestamp
- Result (success/failure)
- Details & notes

Logs retained for 7 years minimum.
