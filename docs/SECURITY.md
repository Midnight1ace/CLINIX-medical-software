# Security Guidelines

## Data Protection

### Encryption
- AES-256 for data at rest
- TLS 1.3 for data in transit

### Access Control
- Role-based access control (RBAC)
- Multi-factor authentication (MFA)
- Session timeout (15 minutes)

### Audit Logging
- All patient access logged
- All data modifications logged
- 7-year retention policy

## HIPAA Compliance

- Administrative safeguards implemented
- Physical safeguards for on-premise deployment
- Technical safeguards with encryption
- Breach notification procedures

## GDPR Compliance

- Data export capability
- Right to be forgotten (data deletion)
- Consent management
- Data minimization

## Incident Response

1. Detection & containment
2. Investigation & analysis
3. Remediation & fixes
4. Notification & reporting
5. Documentation & review

See SECURITY_COMPLIANCE.md for detailed procedures.
